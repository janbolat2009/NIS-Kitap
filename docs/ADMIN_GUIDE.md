# NIS Kitap — 100 кітап, рейтинг и награды: руководство администратора

## Роли

| Роль | Что может |
|---|---|
| `student` | свой прогресс, отправка книги на подтверждение, лидерборд |
| `librarian` | подтверждение прочтений, выдача/возврат, аналитика, предложение и выдача наград |
| `director` | аналитика, одобрение наград, импорт учеников и шаңыраков, журнал действий |
| `project_admin` | всё, что библиотекарь и директор, + корректировка очков и формула очков |
| `teacher` | решение по доп. баллам только своего предмета (`subject`) |
| `curator` | зарезервирована, сейчас без доп. прав |
| `super_admin` | всё + назначение ролей |

Матрица прав — `src/lib/permissions.js`. Из неё же генерируется `firestore.rules`,
поэтому интерфейс и сервер проверяют одно и то же. Роль, переданная клиентом, не принимается.

## Как добавить email директора, библиотекаря и Ардак К.

1. Откройте `config/access.json` и замените плейсхолдеры реальными email (строчными буквами).
2. `npm run rules:build` — пересобирает `firestore.rules`.
3. `npx firebase login` (один раз), затем `npm run rules:deploy`.
4. Задеплойте сайт (push в `main` или `vercel --prod`), чтобы интерфейс увидел роли.

Вход возможен только с подтверждённым email (Google-аккаунт или ссылка из письма).

## Дополнительные роли без изменения кода

Технический администратор открывает **/admin/roster → Роли** и назначает роль по email
(Firestore `roles/{email}`, действие пишется в журнал). Себе роль назначить нельзя.

## Импорт шаңыраков и классов

`/admin/roster → Шаңыраки и классы → Выбрать файл`. CSV (или JSON-массив с теми же ключами):

```
shanyrak_name,class_name,curator_name,academic_year
```

Готовый файл на 2026–2027: `import-templates/shanyraks_2026-2027.csv` (18 шаңыраков, 70 классов,
собран из «список кураторов 2026-27» и «Шаңырақ лидерлері»). Перед импортом показывается проверка;
ошибки (класс в двух шаңыраках, неверный учебный год) блокируют импорт.

## Импорт учеников

```
email,full_name,class_name,academic_year
```

`full_name` — «Фамилия Имя». В публичном рейтинге показывается только «Ф. Имя, класс».
История по годам хранится в `memberships`.

## Список «100 книг»

Источник — `scripts/hundred-books.source.mjs` (протокол Правления № 9 от 04.03.2021).
`npm run hundred:build` пересобирает `public/data/hundred-books.json` и связывает книги с каталогом
по стабильному ID (`src/lib/bookId.js`). Ручные соответствия (сборники, другое написание) —
`MANUAL_LINKS` в `scripts/build-hundred-books.mjs`.

## Очки

По умолчанию: 100 за подтверждённую книгу, +25 за книгу из «100 кітап», +20 за содержательный отзыв,
значки за 10/25/50/75/100 книг. Меняется в **/admin → Формула очков**. Очки — журнал (`points_ledger`):
записи не изменяются и не удаляются, одно событие не может быть начислено дважды.
Очки чтения не связаны со школьными оценками; «доп. баллы по предмету» — только предложение учителю.
